# 报文解析清单

本文档说明 NetScope 需要从原始帧里解析哪些内容、为什么需要、做到什么程度，以及当前实现到哪一步。

当前进度：**阶段 1–4 全部完成**。链路层、网络层（IPv4/IPv6）、传输层（TCP/UDP/ICMP）
已解析并接入列表/详情树/统计；代码在 `src/netscope/core/parser.py`，
验收用例见 `tests/test_parser.py`。

## 1 目标与边界

解析的目标是三件事：

1. 满足需求里"逐层展开关键字段"的显示要求；
2. 给长度分布、IP 版本、协议分布等统计提供数据；
3. 给 SYN 泛洪、ICMP 回声异常等告警提供判定依据。

解析只做"首部字段"，不做应用层协议识别，不做载荷还原，不做分片重组，不校验校验和。

## 2 需求必显字段

| 层 | 字段 | 说明 |
|---|---|---|
| 数据链路层 | 目的 MAC | 冒号分隔小写十六进制 |
| 数据链路层 | 源 MAC | 同上 |
| 数据链路层 | 以太网类型 | VLAN 帧显示剥掉标签后的内层类型 |
| 网络层 | 源 IP | IPv4 点分十进制 / IPv6 压缩形式 |
| 网络层 | 目的 IP | 同上 |
| 网络层 | IP 版本 | 4 / 6 |
| 网络层 | TTL | IPv6 对应"跳数限制" |
| 网络层 | 协议号 | 6 TCP / 17 UDP / 1 ICMP / 58 ICMPv6 / 其它数值 |
| 传输层 | TCP/UDP 源端口 | 非 TCP/UDP 显示"不适用" |
| 传输层 | TCP/UDP 目的端口 | 同上 |
| 传输层 | TCP 标志 | 界面只显示 SYN / ACK / FIN / RST 四个 |

附加字段（默认折叠，可在设置里关闭）：IPv4 标识、DF/MF、片偏移、首部长度、TCP 序号/确认号、窗口、UDP 长度、ICMP 类型/代码。

## 3 统计与告警依赖

这些字段不一定显示，但必须解析出来：

| 字段 | 用途 |
|---|---|
| `ip_length`（主口径） | IPv4 取总长度；IPv6 取 40 + 载荷长度；非 IP 退回帧长。长度直方图、三段柱状图 |
| `frame_len` / `caplen` | 帧长口径对照、详情里的"帧长/抓包长度" |
| `ip_version` | IPv4 / IPv6 / 其它柱状图 |
| `protocol` | 协议分布、列表协议列 |
| TCP 标志 | SYN 泛洪判定（SYN 计数、SYN/SYN-ACK 比） |
| 目的 IP、目的端口 | 告警定位目标 |
| ICMP 类型/代码 | 回声请求/应答异常 |
| MF 标志、片偏移 | 大包/分片异常 |

## 4 必须处理的协议细节

| 情况 | 处理方式 | 原因 |
|---|---|---|
| VLAN 标签 | 0x8100 / 0x88A8 / 0x9100，最多剥两层 | 不剥标签会把 0x8100 当成协议类型，后面全错 |
| QinQ | 两层标签都记录，取最内层 EtherType | 运营商/实验环境会出现 |
| IPv4 选项 | IHL > 5 时按 IHL×4 跳过选项 | 否则 TCP 端口会读错位置 |
| IPv6 扩展头 | 逐跳(0)、路由(43)、分片(44)、目的选项(60)、AH(51) 逐层遍历；ESP(50) 停止 | 不遍历就取不到真正的传输层协议号和端口 |
| IPv6 分片 | 片偏移 > 0 时没有传输层头，端口置空 | 避免把载荷当端口 |
| 以太网填充 | 用 IP 声明的总长度，不把 padding 算进载荷 | 最小 60 字节帧会带填充 |
| 截断帧 | caplen 不足首部长度时能填多少填多少，标记 `truncated` | 不能崩，也不能把越界数据当字段 |
| 声明长度 > 捕获长度 | 统计用声明长度，详情标"截断" | 统计口径按报文真实长度 |
| 非 IP（ARP 等） | 归入"其它"，链路层照常显示 | 需求要求统计"其它数据" |

## 5 不解析的内容

- 应用层协议（DNS、HTTP、TLS 等）的内容；
- TCP 选项逐项（MSS、SACK、时间戳），只按 Data Offset 跳过；
- 校验和验证；
- IP 分片重组；
- IPsec ESP 解密、IPv6 jumbogram 的完整支持；
- 载荷内容（只在十六进制视图里原样显示）。

## 6 分阶段实现

| 阶段 | 内容 | 状态 |
|---|---|---|
| 1 | 链路层：MAC、外层/内层 EtherType、VLAN ID、payload 偏移、截断标记 | **已完成** |
| 2 | 网络层：IPv4/IPv6 首部、扩展头、分片、IP 长度 | **已完成** |
| 3 | 传输层：TCP/UDP/ICMP 端口、标志、类型 | **已完成** |
| 4 | 把解析结果接到列表、详情树、长度/IP 版本统计 | **已完成** |

`ParsedFrame` 现在包含 `eth` / `ipv4` / `ipv6` / `transport` 四个可选段，
派生属性 `protocol`、`ip_version`、`ip_length`、`src_ip`/`dst_ip` 供列表、
统计与告警直接使用；后续扩展不需要重写界面层。

## 7 数据结构规划

```text
ParsedFrame
├─ frame            原始帧（ts / caplen / origlen / bytes）
├─ eth              EthernetInfo
│  ├─ dst_mac
│  ├─ src_mac
│  ├─ outer_type    最外层 EtherType
│  ├─ ether_type    剥掉 VLAN 后的内层类型
│  ├─ vlan_ids      VLAN ID 列表（最多两层）
│  └─ payload_offset 网络层首部在帧中的偏移
├─ ipv4             IPv4Info（版本、IHL、总长度、标识、DF/MF、片偏移、TTL、协议号、源/目的 IP、载荷偏移）
├─ ipv6             IPv6Info（版本、载荷长度、最终协议号、跳数限制、源/目的 IP、扩展头、分片信息）
├─ transport        TransportInfo（协议名、源/目的端口、TCP 标志、序号/确认号、窗口、ICMP 类型/代码、载荷偏移）
├─ truncated        是否被截断
├─ malformed        首部是否畸形
└─ 派生属性：protocol（TCP/UDP/ICMP/ARP…）、ip_version（4/6/0）、
   ip_length（主统计口径）、src_ip/dst_ip
```

## 8 验收用例

| 用例 | 构造 | 期望 | 测试 |
|---|---|---|---|
| 普通以太网 | 14 字节头 + IPv4 | MAC、类型 0x0800、payload 偏移 14 | `test_basic_ethernet` |
| 单层 VLAN | 0x8100 + TCI 100 + 0x0800 | VLAN ID 100、内层 IPv4、偏移 18 | `test_single_vlan` |
| QinQ | 0x88A8 + 0x8100 + 0x0800 | 两个 VLAN ID、内层 IPv4、偏移 22 | `test_qinq` |
| IPv4 选项 | IHL=6 | TCP 端口读在选项之后 | `test_ipv4_options_are_skipped` |
| IPv4 分片 | 片偏移 > 0 | 无传输层端口，协议列显示"IPv4 分片" | `test_ipv4_fragment_no_transport` |
| IPv6 扩展头 | 逐跳扩展头 + UDP | 端口正确、扩展头列出 | `test_ipv6_hop_by_hop_extension` |
| IPv6 分片 | 分片头偏移 > 0 | 端口置空 | `test_ipv6_fragment_no_ports` |
| 未知 EtherType | 0x88CC | 协议显示 LLDP，不崩 | `test_unknown_ether_type` |
| 截断帧 | 10 字节 | 标记截断，MAC 显示"—" | `test_truncated_ethernet` |
| 只有半截 VLAN 标签 | 16 字节 | 标记截断，已读出的字段保留 | `test_truncated_vlan_header` |

## 9 统计口径（已生效）

列表"长度"列与长度分布/三段柱状图按 **IP 分组长度**（主口径）：
IPv4 取总长度；IPv6 取 40 + 载荷长度；非 IP 退回帧长；详情里同时给出帧长与抓包长度。
