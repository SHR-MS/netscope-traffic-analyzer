# 测试指南

按顺序做，大约 20 分钟能跑完全部自动化与功能测试（1 天稳定性测试除外）。

## 准备

1. Python 3.11+，在仓库根目录建虚拟环境并装依赖：

   ```powershell
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. 安装 Npcap（真实抓包必需）：https://npcap.com/#download
   安装时**取消勾选** “Restrict Npcap driver's access to Administrators only”，装完重启。

## 一、自动化测试（不需要 Npcap）

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -t . -v
.venv\Scripts\python.exe src\smoke_test.py
.venv\Scripts\python.exe verify_e2e.py
```

或者双击 `scripts\运行自动化测试.bat`。

通过标准：`OK`、`SMOKE OK`、`E2E: PASS`。

## 二、界面功能测试（演示模式，不需要 Npcap）

```powershell
.venv\Scripts\python.exe src\main.py --demo
```

| 检查项 | 怎么看 | 预期 |
|---|---|---|
| 报文列表 | 主表格 | 序号/时间/源/目的/协议/长度/信息，协议有颜色 |
| 链路层 | 点一行看左下详情树 | 目的 MAC、源 MAC、类型 |
| 网络层 | 详情树 | 版本、源/目的 IP、TTL、协议号 |
| 传输层 | 详情树 | 源/目的端口、`SYN=.. ACK=.. FIN=.. RST=..` |
| 十六进制 | 右下窗格 | 偏移 + hex + ASCII |
| 长度分布 | 右侧第 1 页 | 折线；可切换对数纵轴 |
| 长度分段 | 右侧第 2 页 | 三根柱：≤46 / 47–1500 / >1500 |
| IP 版本 | 右侧第 3 页 | 三根柱：IPv4 / IPv6 / 其它 |
| 告警 | 右侧第 4 页（等 30~90 秒） | 演示模式每 30 秒轮换一种异常，会自动出现告警 |

## 三、真实抓包测试（需要 Npcap + 管理员）

1. 双击 `scripts\启动NetScope.bat`（会自动申请管理员权限）
2. 网卡选**带 IP 的物理网卡**（例如 `Intel(R) Wi-Fi 6E AX211 (10.x.x.x)`），
   不要选 `...-Npcap Packet Driver (NPCAP)-0000`，那是原始 802.11 抓包接口
3. F5 开始，刷几个网页，Shift+F5 停止
4. 验证：列表出现真实 IP、协议为 TCP/UDP/ICMP，详情树字段与 Wireshark 一致
5. **文件 → 另存为** 保存 pcap，再 **文件 → 打开** 回放，列表与图表应重新出现

## 四、告警测试（可选扩展功能验证）

前提：已断开 VPN（否则报文走隧道抓不到），NetScope 正在抓 Wi-Fi 网卡。

双击 `scripts\告警测试.bat`，脚本会：

1. 自动识别默认网关，并选同网段空闲地址作为测试目标（不会打网关）
2. 依次发送 SYN 泛洪、ICMP 回声泛洪、无请求应答、大包回声
3. 全过程写入 `告警测试日志.txt`

完成后“告警”页应出现四条：

| 规则 | 级别 | 说明 |
|---|---|---|
| SYN_FLOOD | critical | 5 秒内 SYN ≥100 且 SYN/SYN-ACK ≥3 |
| ICMP_ECHO_FLOOD | critical | 5 秒内 echo request ≥50 |
| ICMP_ORPHAN_REPLY | warning | 5 秒内 echo reply ≥20 且 request ≤5 |
| ICMP_BIG_ECHO | info | echo request 载荷 >800 B 或分片 |

阈值在 `src/netscope/config.py` 的 `AlertConfig` 里，可按实验环境调整。

## 五、1 天稳定性测试

管理员终端先关休眠：

```powershell
powercfg /change standby-timeout-ac 0
powercfg /change hibernate-timeout-ac 0
```

1. 双击 `scripts\启动NetScope.bat`，选 Wi-Fi 网卡，F5 开始抓包
2. 正常使用电脑，期间可随时看状态栏：运行时长、CPU、内存、包数
3. 第二天回来截图状态栏（证明运行 ≥ 24 小时）。运行时长按程序启动算起，校园网半夜掉线不影响计时，重连后按 F5 继续抓包即可
4. **文件 → 打开捕获目录**，取出 `资源占用.csv` 与 pcap 文件
5. 用 Excel 打开 CSV 统计 CPU/内存均值与峰值，写进报告"资源消耗分析"

判定标准：

| 指标 | 预期 |
|---|---|
| 运行时长 | 连续 ≥24 小时不断 |
| 内存 | 基本稳定（列表 5000 行上限、统计为计数） |
| CPU | 空闲网络下很低，大量流量时上升但不卡机 |
| 磁盘 | 捕获目录按流量增长，单段 64 MB 自动切换 |
